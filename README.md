## Функционал

Инструмент включает в себя 6 основных модулей:

*   **[1] 📢 Webhook Spammer** — Многопоточный спам сообщениями через Discord Webhook.
*   **[2] 💬 Channel Spammer** — Спам сообщениями в конкретный текстовый канал по его URL.
*   **[3] 📨 Mass DM Friends** — Рассылка личных сообщений всем пользователям из списка друзей.
*   **[4] 👤 Token Information** — Получение полной информации об аккаунте по его токену.
*   **[5] 🕵️ Scrape Server Members** — Парсинг ID всех участников указанного сервера в файл.
*   **[6] 💣 Mass DM from Scraped File** — Рассылка личных сообщений по списку ID, полученному с помощью парсера.

## Установка

Для работы скрипта необходим **Python 3.9** или выше.

### 1. Клонирование репозитория
```bash
git clone https://github.com/ВАШ_НИКНЕЙМ/ВАШ_РЕПОЗИТОРИЙ.git
cd ВАШ_РЕПОЗИТОРИЙ

2. Установка зависимостей

Убедитесь, что у вас установлены все необходимые библиотеки:

Bash

pip install requests

Руководство по использованию

    Запустите скрипт:

    Bash

    python synepsy.py

    (или укажите имя вашего главного файла)

    Выберите действие:
    При запуске вы увидите главное меню. Введите цифру, соответствующую функции, которую вы хотите использовать.

    Следуйте инструкциям:
    Каждый модуль запросит у вас необходимые данные (токен, URL, текст сообщения и т.д.). Вводите их внимательно.

Подробное описание функций
[1] Webhook Spammer

    Что делает: Отправляет неограниченное количество сообщений на указанный URL вебхука в несколько потоков для максимальной скорости.
    Что запрашивает: URL вебхука, текст сообщения, имя отправителя (опционально), количество потоков.

[2] Channel Spammer

    Что делает: Отправляет заданное количество сообщений в текстовый канал от имени вашего аккаунта.
    Что запрашивает: Текст сообщения, токен аккаунта, URL для отправки сообщений (API-endpoint канала), количество сообщений.

[3] Mass DM Friends

    Что делает: Отправляет одно и то же сообщение всем пользователям из вашего списка друзей.
    Что запрашивает: Токен аккаунта, текст сообщения, задержку между отправками.
    Рекомендация: Ставьте задержку 2–5 секунд для снижения риска бана.

[4] Token Information

    Что делает: Собирает и отображает всю доступную информацию об аккаунте по его токену.
    Что запрашивает: Токен аккаунта.
    Вывод: Никнейм, ID, Email, телефон, статус 2FA, платежная информация, список друзей и серверов.

[5] Scrape Server Members

    Что делает: Получает список всех участников сервера и сохраняет их никнеймы и ID в файл members.txt.
    Что запрашивает: Токен аккаунта, ID сервера (Guild ID).
    Внимание: Эта функция может не работать на серверах, где скрыт список участников или у вашего аккаунта нет прав на его просмотр.

[6] Mass DM from Scraped File

    Что делает: Использует файл, созданный парсером, для рассылки сообщений всем участникам сервера.
    Что запрашивает: Токен аккаунта, текст сообщения, задержку.
    Внимание: Это самая рискованная функция. Рассылка не-друзьям почти гарантированно приведет к блокировке.
